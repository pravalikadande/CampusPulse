# CampusPulse

CampusPulse is a campus activity analytics project built using Excel, MySQL, Python, and Power BI.

## Project Overview

The project analyzes four major campus activities:

- Library Activity
- Lab Utilization
- Canteen Sales
- Transport Activity

The goal is to organize campus data, perform SQL and Python analysis, and present the results through an interactive Power BI dashboard.

## Tools Used

- Excel – Data source and initial analysis
- MySQL – Database management and SQL analysis
- Python – Data analysis and visualization
- Power BI – Interactive dashboard
